# Ultimate VJ Homebrew tap

Official installation metadata for Ultimate VJ binary releases.

```sh
brew tap weswalz/ultimatevj
```

Install Ultimate VJ after updating Homebrew:

```sh
brew update
brew install --cask weswalz/ultimatevj/ultimatevj
```

For later releases, quit UltimateVJ between shows, then run:

```sh
brew update
brew upgrade --cask ultimatevj
```

Requirements: Homebrew, Apple Silicon, macOS 26 or later. Saved sets and venue media should remain in their persistent locations.

Official downloads: https://github.com/weswalz/ULTIMATEVJ-releases
